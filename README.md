# Vinayaka M — Personal Portfolio

A responsive personal portfolio website created for the IPS assignment using AI-assisted development and front-end code.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts

## Project files
- `index.html` — website structure and content
- `style.css` — responsive design and styling
- `script.js` — mobile menu and dynamic year

## How to run
Open `index.html` in any modern browser.

## GitHub
Create a new GitHub repository, upload these three files, and commit them.

## Vercel deployment
1. Sign in to Vercel with GitHub.
2. Import this repository.
3. Keep the default settings.
4. Click Deploy.
5. Copy the live website URL for your assignment.

## Before submitting
Replace `your-email@example.com` and the GitHub/LinkedIn links in `index.html` with your actual links.
